# Academic Presentation Web Skill for Cursor

## Project-level installation
Copy `.cursor/skills/academic-presentation-web/` into the root of the project opened in Cursor.

Expected path:
`your-project/.cursor/skills/academic-presentation-web/SKILL.md`

## Global installation
Copy the `academic-presentation-web` folder to:
`%USERPROFILE%\\.cursor\\skills\\academic-presentation-web\\SKILL.md`
Create parent folders if needed.

## Usage
Open the project in Cursor and use Agent chat. Invoke `/academic-presentation-web` if it appears in the skill picker, or attach it with `@academic-presentation-web`. If it is not listed, verify the folder/file names and reload the workspace.

Example prompt:
“Use academic-presentation-web to build a Chinese academic presentation website about [topic]. Use chapter scrolling with interactive architecture/process explanations. Preserve technical accuracy and citations. Implement the page, preview it, and fix any issues you can verify.”

Skills guide the agent; they do not guarantee perfect output. For existing repositories, let Cursor inspect the current framework first.
